# Artefatos dos runs na nuvem

Snapshots dos melhores modelos e curvas de avaliação dos treinos rodados na
sessão cloud, salvos periodicamente como proteção contra reciclagem do
sandbox. Os runs completos oficiais são os da máquina local; estes servem de
backup e de ponto de partida (os best_model.zip são utilizáveis diretamente
pelo traffic-rl evaluate/compare copiando-os para results/runs/<tag>/seed_<s>/).
